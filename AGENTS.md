# Watchdog — правила для агентов

## О проекте

Watchdog — сервис мониторинга Telegram-чатов. Пассивно наблюдает за группами,
собирает сообщения, профили участников и метаданные через MTProto-клиент (Telethon).
Экспортирует данные для дальнейшего анализа.`esearch.md`.

---

## Правила взаимодействия

### 1. Язык — русский

Все ответы, описания, комментарии в коде и коммит-сообщения — на русском языке.
Код (имена переменных, функций, классов) — на английском, как принято.

### 2. Чистый текст — stop-slop

При генерации текстов (документация, описания, README) применять принципы stop-slop:

- Без канцелярита и.water-фраз («стоит отметить», «является», «представляет собой»)
- Без filler-слов («очень», «достаточно», «в целом», «по сути»)
- Без ложной вежливости и оговорок
- Короткие предложения, конкретика, факты
- Активный залог, прямые формулировки

### 3. Модели — GLM Coding Plan по умолчанию

Для простых и одношаговых задач (чтение файла, простая правка, факт,
форматирование, небольшие скрипты) использовать **GLM Coding Plan**
(провайдер `zai-coding-plan/glm-4.7`). На этой модели много ресурсов —  
это дефолтный выбор для большинства тривиальных задач с контекстом до 200к токенов.

### 4. Параллельность — Orca

Для параллельной обработки использовать Orca — несколько worktrees/terminals
с разными агентами, работающими одновременно. Конкретные сценарии:

- **Несколько независимых задач** → `orca worktree create --agent <id> --prompt "..."` для каждой задачи, каждый worktree работает в своём терминале параллельно.
- **Координированная работа** (task DAG, зависимости, wait-for-completion) → `orca orchestration run-create` + `task-create` + `worker-start`.
- **Handoff** (передать задачу другому агенту без контроля) → `orca worktree create` или `orca terminal send` без orchestration overhead.

Не сериализовать то, что может идти параллельно. Создавать worktrees одним
батчем, потом `check --wait` для сбора результатов.

### 5. Документация библиотек — Context7

Для получения актуальной информации о библиотеках и фреймворках использовать
Context7 MCP-сервер **до** веб-поиска:

- `resolve-library-id` → найти library ID
- `query-docs` → получить актуальную документацию

Приоритет: Context7 → веб-поиск → собственные знания (в таком порядке).
Особенно важно для Telethon, у которого API обновляется.

### 6. Интерактивные команды — Orca terminal

Когда нужна команда с интерактивным вводом от пользователя (SMS-коды, пароли, подтверждения), создавать Orca terminal и отправлять команду туда:

```bash
# Создать терминал
orca terminal create --worktree active --title "<название>" --json

# Отправить команду
orca terminal send --terminal <handle> --text "<команда>" --enter --json
```

Пользователь видит вкладку в Orca и может ввести данные. Не просить пользователя запускать команды вручную в своём терминале — создавать Orca terminal.

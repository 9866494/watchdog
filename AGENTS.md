# Watchdog — правила для агентов

## О проекте

Watchdog — сервис мониторинга Telegram-чатов. Пассивно наблюдает за группами,
собирает сообщения, профили участников и метаданные через MTProto-клиент (Telethon).
Данные читаются через MCP-сервер (tools `search_messages`, `get_chat_stats` и др.).

Стек: Docker Compose + tg-archive (Telethon → SQLite) + watchdog-mcp (Python MCP, stdio).

---

## Правила взаимодействия

### 1. Язык — русский

Все ответы, описания, комментарии в коде и коммит-сообщения — на русском языке.
Код (имена переменных, функций, классов) — на английском, как принято.

### 2. Чистый текст — stop-slop

При генерации текстов (документация, описания, README) применять принципы stop-slop:

- Без канцелярита и water-фраз («стоит отметить», «является», «представляет собой»)
- Без filler-слов («очень», «достаточно», «в целом», «по сути»)
- Без ложной вежливости и оговорок
- Короткие предложения, конкретика, факты
- Активный залог, прямые формулировки

### 3. Документация библиотек — Context7

Для получения актуальной информации о библиотеках и фреймворках использовать
Context7 MCP-сервер **до** веб-поиска:

- `resolve-library-id` → найти library ID
- `query-docs` → получить актуальную документацию

Приоритет: Context7 → веб-поиск → собственные знания (в таком порядке).
Особенно важно для Telethon, у которого API обновляется.

### 4. Настройка проекта — bootstrap

Не собирать окружение руками. Использовать `./scripts/bootstrap.sh`:

```bash
./scripts/bootstrap.sh          # полный сетап: проверки → env → build → auth → sync → verify
./scripts/bootstrap.sh --check  # только проверки (docker, .env, сессия, БД)
./scripts/bootstrap.sh --sync   # инкрементальная синхронизация чатов
./scripts/bootstrap.sh --verify # проверка ответа MCP-сервера (stdio handshake)
```

Скрипт идемпотентен: повторный запуск делает только недостающие шаги.

### 5. Интерактивная авторизация

Первый `docker compose run --rm tg-archive --sync` запрашивает телефон, SMS-код
и (при 2FA) пароль через stdin. Агент должен выполнить команду в PTY-терминале
своего окружения и передать ввод пользователя. Коды и пароли в логи не писать,
в git не коммитить.

### 6. Секреты

`.env` содержит api_id/api_hash и номер телефона. В git не коммитить (уже в
.gitignore). При отладке маскировать значения в выводе.

### 7. Именование образов

Образы фиксируются в docker-compose.yml (`watchdog-tg-archive:latest`,
`watchdog-mcp:latest`) и не зависят от имени каталога клона. Не переименовывать.
